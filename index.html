Influence Of AI In Credit Card Transaction Process

ABSTRACT

The Influence of Artificial Intelligence in Credit Card Transaction Process is designed to enhance the security of online credit card transactions. The system uses Artificial Intelligence (AI) and Facial Recognition to verify the identity of the cardholder before processing a transaction.

The captured facial image is compared with the registered user data stored in a secure database. If the face matches, the transaction is approved; otherwise, it is rejected, preventing unauthorized access and reducing the risk of credit card fraud.

This project provides a smart, secure, and efficient solution for protecting digital payments, improving customer trust, and ensuring safer financial transactions.

Asset Management System (AMS)

ABSTRACT

Asset Management system is used to maintain assets of a company, which requires significant time if done without software. Every organization has its own Asset Management System to perform resource activities.

Managing, utilizing, and tracking assets is a significant task of the IT team, whose main job is to maintain all company assets like laptops and other devices, and keep track of their condition.

To support IT teams, electronic-based systems called AMS - Asset Management Systems - were created. Organizations previously maintained assets with spreadsheets, a tedious process. This application is a cost-effective way to manage asset data simply.

This project is a web application accessible through a PC with an internet connection. It allows the IT team to provide various permission types to other IT members and manage asset data, status, category, location, and more.

Smart Intern Management System (SIMS)

ABSTRACT

SIMS is a centralized web application designed to streamline end-to-end management of interns within an organization. It eliminates manual spreadsheet tracking and provides a single source of truth for intern data.

The platform handles intern onboarding, role assignment, attendance, task allocation, and performance monitoring. Administrators can manage stipend payments, generate offer and completion letters, and track each intern's progress through interactive dashboards.

Built with React on the frontend and Django REST Framework on the backend, SIMS offers role-based access for admins, mentors, and interns, with tailored dashboards for each user.

By automating repetitive HR tasks and centralizing communication, SIMS significantly reduces administrative overhead and improves transparency across the internship lifecycle.

Dynamic Timesheet Management System (DTMS)

ABSTRACT

DTMS is an enterprise-grade web application that helps organizations accurately capture employee work hours, attendance, and project-wise time allocation in real time.

Employees can log daily tasks against assigned projects, while managers review, approve, or reject submissions through an intuitive approval workflow. The system supports flexible work schedules, leave tracking, and overtime calculations.

Powered by a React + Vite frontend and a Django backend, DTMS provides analytical dashboards with charts and exportable reports, helping leadership monitor productivity, billable hours, and resource utilization across teams.

With granular role-based permissions and audit logs, DTMS ensures data integrity and compliance, replacing scattered spreadsheets with a unified, scalable timesheet solution.
